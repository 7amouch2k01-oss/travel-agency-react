# Wanderlust Travel Agency - React Website

Welcome to the **Wanderlust Travel Agency** project! This is a modern, responsive landing page built with **React** and **React-Bootstrap**.

## 🌟 Features

- **Responsive Navigation**: A sticky navbar with links to different sections of the page.
- **Dynamic Carousel**: An eye-catching hero carousel showcasing beautiful travel destinations with cross-fade effects.
- **Destination Highlights**: Three detailed cards featuring popular travel spots like Paris, Santorini, and Bali, organized in a responsive grid.
- **Contact Form**: A clean and functional contact form for user inquiries.
- **Professional Footer**: Includes copyright info and quick links.
- **React Best Practices**: Uses React Fragments, functional components, and organized asset management.

## 🛠️ Technologies Used

- **React**: Frontend library for building the user interface.
- **React-Bootstrap**: For responsive components and grid layout.
- **Bootstrap 5**: Core styling framework.
- **Node.js & npm**: Package management and build environment.

## 🚀 Getting Started

To run this project locally, follow these steps:

### 1. Clone the repository
\`\`\`bash
git clone https://github.com/7amouch2k01-oss/travel-agency-react.git
cd travel-agency-react
\`\`\`

### 2. Install dependencies
\`\`\`bash
npm install
\`\`\`

### 3. Run the application
\`\`\`bash
npm start
\`\`\`
The app will be available at \`http://localhost:3000\`.

## 📂 Project Structure

- \`src/App.js\`: The main component containing the website's structure and logic.
- \`src/index.js\`: The entry point that renders the React app.
- \`public/assets/\`: Contains the images used in the carousel and destination cards.
